# aagrawal207/homebrew-tap

Homebrew casks for apps by [@aagrawal207](https://github.com/aagrawal207).

## Bar Keeper's Friend

A menu bar manager for macOS 26 (Tahoe). See the
[project README](https://github.com/aagrawal207/bar-keepers-friend#readme) for what it does.

```sh
brew install --cask aagrawal207/tap/bar-keepers-friend
```

Upgrade with `brew upgrade --cask bar-keepers-friend`. Uninstall with
`brew uninstall --cask bar-keepers-friend`; add `--zap` to also remove its preferences, cache, and logs.

Report problems with the app in its
[issue tracker](https://github.com/aagrawal207/bar-keepers-friend/issues).
